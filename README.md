## Автоматизация пользовательских сценариев для учебного сервиса "Доска объявлений"

Сервис: [Доска объявлений](https://qa-desk.stand.praktikum-services.ru/)

Проект включает автоматизацию основных пользовательских сценариев.

---

## Функциональность и проверка

| **Функциональность**      | Что проверить |

| **Регистрация пользователя**       | Успешная регистрация с уникальным email. Попытка зарегистрироваться повторно |

| **Авторизация пользователя**       | Авторизация ранее зарегистрированного пользователя |

| **Создание объявления** | Успешное создание объявления в любой категории |


---

## Не реализованные автотесты


- **Редактирование объявления**  
  Обнаружен баг: при нажатии на кнопку "редактировать" система переводит на создание нового объявления
- **Удаление объявления**  
  Функция не реализована
